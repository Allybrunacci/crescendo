crescendo-notation.woff2
  A subset of Bravura, the SMuFL music font by Steinberg Media Technologies GmbH,
  containing only the music symbols Crescendo draws. Because it is modified (subset),
  it is renamed “Crescendo Notation”, as the SIL Open Font License requires for the
  Reserved Font Name “Bravura”. Licence: OFL-Bravura.txt (SIL Open Font License 1.1).
